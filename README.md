# Shift Audit Engine

Shift Audit Engine is a full-stack security incident tracking and management application featuring real-time WebSockets and analytics telemetry.

## Features

- Real-time incident tracking and operator monitoring via WebSockets
- Advanced analytics telemetry dashboard for operational insights
- Comprehensive compliance checklist management and persistent audit logging

## Tech Stack

- **Frontend:** React, Vite, WebSockets, Tailwind CSS
- **Backend:** Node.js, Express, WebSockets
- **Database:** Supabase, PostgreSQL
